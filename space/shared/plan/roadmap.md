# Roadmap

## Purpose

This file tracks high-level cross-task direction for the repository.

## Current Roadmap

### Workspace Foundation

- complete the minimal `/space` runtime structure
- stabilize routing, planning, history, and task state conventions
- make agent recovery reliable across sessions

### Platform Foundation

- define service boundaries around `apps/`, `services/`, `plugins/`, and `dify/`
- keep Dify customization minimal and controlled
- establish deterministic Pokemon data and tool flows

### Product Direction

- support Pokemon knowledge Q&A
- support battle analysis and type-effectiveness reasoning
- support team recommendation and future multi-agent workflows
